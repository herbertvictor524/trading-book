# trading-book

A simple trading journal with win rate tracking, asset analysis, and live-style charts in a customizable UI.

## Features

- Add and remove trades with entry, exit, quantity, and notes
- Calculate total P/L, win rate, and average return
- See the best-performing assets by percentage yield
- Get quick suggestions based on recent asset performance
- Review human notes and reflections for each trade
- Switch between light and dark themes and multiple accent colors
- Persist data locally in the browser using localStorage

## Tech stack

- React
- TypeScript
- Vite
- Recharts

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL in your browser.
